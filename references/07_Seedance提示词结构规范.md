# Seedance 2.5（兼 2.0）提示词结构规范

当目标视频模型为 **Seedance 2.5 / 2.5 flash（或 2.0）** 时读取本文件。依据火山方舟官方《Doubao Seedance 2.5 系列提示词指南》与一线实战规则整理。

---

## 1. Seedance 2.5 核心能力与 2.0 差异

| 维度 | Seedance 2.5 / 2.5 flash | Seedance 2.0 |
| :--- | :--- | :--- |
| **单段时长** | 最长 **30 秒**直出 | 4–15 秒 |
| **单次参考素材上限** | 2.5：30 图 / 10 视频 / 10 音频；flash：10 图 / 5 视频 / 5 音频 | 较低 |
| **时间戳响应** | **原生响应整数秒时间戳**（如 `0s-3s`、`3s-8s`） | 不响应时间戳，仅响应 `镜头 N` |
| **多视图主体参考** | 支持（1–5 主体单/多视图均可；超 5 主体建议单视图或拆为多张单视图） | 不建议多视图 |
| **画幅与格式** | 支持 `[0.4, 2.5]` 自由宽高比；延长/编辑建议输出 `MOV` 保色温与声画一致 | 固定 6 档宽高比 |

### 有锁定 vs 无锁定任务（2.5 新增机制）
- **有锁定（自动锁定输出宽高比/时长）**：
  - **首帧 / 首尾帧**：优先通过 `first_frame` / `last_frame` 参数传入，**严格锁定首帧宽高比**（尾帧画幅若与首帧不一致会被拉伸，务必保证首尾帧同画幅）。若改用 `reference_image` 并在词中写「图片 1 为首帧，图片 2 为尾帧」，则不锁定宽高比，对齐度略降。
  - **视频编辑**：锁定原视频宽高比与时长；提示词直接写 `编辑/增加/删除/修改 <视频N>`，**不要加“参考”二字**。
  - **视频延长**：锁定原视频宽高比；用 `向前/向后延长、延续、续写 <视频N>` 触发，输入输出均建议 `MOV`。
- **无锁定（可自定义画幅与时长）**：
  - **参考生视频（R2V）**：1–8 个主体图效果最稳（1–5 个主体音视频最稳）。
  - **多宫格分镜/故事板**：适合 **15 格以内**简约线稿/火柴人分镜（不推荐脏乱 AI 锐化图或图上写满字），非严格对齐，模型会自主补全。
  - **多关键帧参考**：需严格按多张独立分镜图顺序生成时使用，**第一句必须写明「以图片 1 至图片 N 的顺序作为关键帧」**。

## 2. 官方四段式提示词结构（T2V / I2V / R2V 通用）

1. **（R2V）素材指代**：
   - 按上传顺序编号（`图片 1` / `视频 1` / `音频 1`），文本逐一写清谁是人物、谁是场景、谁是道具、谁是音色；**绝不只在图片里写文字标注**。
   - **极关键**：多人物视频必须**按人物首次出场顺序上传参考图并编号**（先出场的放图片 1），否则极易角色错位/串脸。
   - 参考素材本身已足够精准时，只做明确指代（如「严格参考视频 1 的动作与运镜」），不赘述细节。
2. **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 核心运镜。
3. **具体情节描述**：
   - 用**连续整数秒时间戳**（如 `0s-3s：... 3s-8s：...`，禁止出现 `0-3s...5-6s` 断档，也不建议用时间戳控频次如“1秒摇头3次”）或 `镜头 N` 切分；也可配合时间点（`第 5s 快速向左横移转场`）或相对时间（`停顿 1 秒`）。
   - 动作优先**概括性描述 + 仅在关键记忆点写细节**（不写解剖学角度如“前臂旋转 45°”）；表情用**具体物理动作描述**（如“眉头微皱、下颌收紧、脸上带着满足的笑容大口吃饭”），少用抽象成语。
   - 镜头语言：常用景别/运镜可直接写；小众专业术语须附描述性解释（如「移焦，前景树木由清晰变模糊，背景人物由模糊变清晰」）；转场写清触发时间与方式。
   - **正向描写为主**；负向控制仅用于**字幕**（`不要字幕` / `不额外加入对白字幕`）与**音频**（`无 bgm，只生成环境音和动作音` / `不要任何声音`）。
4. **结尾**：补充贯穿全片的机位/运镜质感、景深、环境音与整体氛围。

## 3. 空间连续性与防翻车清单（官方 FAQ + 导演硬约束）

| 常见翻车现象 | 根因 | 提示词与素材侧解法 |
| :--- | :--- | :--- |
| **角色对应错误 / 串脸** | 参考图顺序与人物首次出场顺序不一致 | **按首次出场顺序排列上传参考图**并同步调整提示词中的 `图片 1/2/3` 编号；跨镜具名追踪建议控制复杂度，人群写成环境整体 |
| **情绪过度响应（眼睛发光）** | “狂热”“极度震惊”等极端情绪词诱发瞳孔蓝/红/黄光 | 改用常规情绪词（如“惊叹”），并显式约束「**人物为正常人眼，眼睛不发光**」 |
| **写“不要字幕”仍出字幕** | 台词后复述词语并追加语气/动作，或参考视频自带字幕 | 禁止台词后复述；差异化语气改用 `角色台词（情绪）：“内容”` 格式；确保参考视频无字幕 |
| **写“禁止 BGM”仍出配乐** | 单一否定词被特效音/氛围音绕过 | 穷举音乐类同义词（`无音乐、无背景音乐、无 BGM、无配乐、无器乐、无旋律、无氛围铺底音`），并在**提示词开头与结尾各写一遍** |
| **画面文字错别字/错拼** | 模型对细小字形自行联想简化 | 英文拆为独立字母按顺序出现；中文文案制成参考图并在词中标 `参考图 N`；非必要尽量后期加字 |
| **草地/树叶出现指纹状纹理** | 输入高分辨率 AI 参考图超过输出视频分辨率 | 缩小输入参考图分辨率使其**不超过输出视频分辨率**（1080p 概率低于 720p） |
| **复杂任务不稳定 / 走位穿模** | 单镜同时叠加多项参考、编辑或过多动作 | 拆分为多个简单任务分步生成；切镜必重锚空间与朝向；单镜不编排“出画再入画”；画外状态变化必须拍在画内；避开镜面/水面实体倒影同框 |
| **全语种无年龄词防风控误杀** | Seedance（2.5 / 2.0 通用）对 `boy/girl/child/young/teen/男孩/女孩/少年/年轻` 等年龄词风控敏感 | 全语种一律删去年龄词，改用角色名、体型、服装、磨损痕迹与动作指代 |
| **跨版本风格不一致** | 2.5 与 2.0 美学偏好差异明显 | 若需延续 2.0 风格，将 2.0 成片作为 2.5 延长任务输入并输出 `MOV` |

## 4. 交付前自查（Seedance 专用）

- [ ] 多人物参考图已按**首次出场顺序**上传并编号绑定，无悬空或错位编号；
- [ ] 时间戳为连续整数秒无断档，全文以正向视觉事实声明为主（仅字幕/BGM 必要处使用兜底禁令）且无年龄词；
- [ ] 多镜切镜/反打时，上一镜被移动、放置或改变状态且仍入画的所有实体（道具/家具/开合构件/随身搭挂物）已按新机位重锚画面左右与前后层次、相对间距及终态朝向/开度；
- [ ] 声画时序与画面时间轴同序：瞬态接触音仅在接触完成瞬间触发（未完成动作不写完成态音效），过程音绑定动作起止。
