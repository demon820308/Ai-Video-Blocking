# 走位动作与道具连续性

## 走位记录模板

| 阶段/时间 | 角色 | 触发点 | 起点 | 路线/经过地标 | 遮挡/交叉 | 终点 | 结束朝向与视线 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

## 动作必须具备

每个动作写明：行动者、触发原因、起点、路径、经过谁的身前/身后、停点、结束姿态和视线。

交叉走位要明确谁先通过、谁等待、是否避让。被遮挡的角色要写清从哪个地标哪一侧重新入画。

## 道具交接检查

1. 交接前谁持有？
2. 谁先伸出哪只手？
3. 接触发生在哪里？
4. 何时算交接完成？
5. 交接后双方各自哪只手空出？
6. 下一镜是否保持一致？

没有明确交接动作，不改变道具归属。
