# 视频生成提示词模板

**镜号 / 时长 / 生成模式：**（标明 T2V / I2V 首帧或首尾帧 / Ref2V；未指定模型时默认通用中文直出，目标为 Seedance / MiniMax H3 时按 `references/07` 或 `08` 专用格式输出）

**起始状态 / 素材绑定：**
- **I2V**：接续指定首帧（如有尾帧一并说明目标落幅）。
- **Ref2V**：绑定 `[人物图A=角色名]`、`[人物图B=角色名]`、`[场景图=场景名]`。
- **T2V**：无参考图，提示词内自包含场景与人物外观。

**精简执行版（默认推荐，直接粘贴生成）：**
> [运镜方式与景别]。（*I2V 写“接续首帧”；Ref2V 先明确对应参考图角色；T2V 补齐场景地标与人物外观*）。[角色名（关键特征）]先[核心动作与走位路线，明确经由某地标及从某人身前/身后通过]，用[左/右手]完成[关键动作/交接]；[其他角色名（关键特征）]在[时机]作出[反应、朝向与视线变化]。落幅时[人物最终位置、朝向、视线与道具归属]。全程保持人物外貌、地标空间、180° 轴线与既有手部道具归属连续稳定，动作按顺序完整落稳。

**分秒场记版（复杂动作或逐秒核对时按需使用）：**
> [0–X秒] [角色名/编号]因[触发点]从[起点]出发，沿[路线]经过[地标]，从[另一人物]身前/身后通过；[遮挡及重新入画说明]。  
> [时间段] [其他角色名]在[明确时刻]作出[反应]，身体[朝向]，目光看向[对象]。  
> [时间段] [接触/递物动作]由[角色]用[左/右手]完成，接触位置为[位置]；交接完成后[道具归属及双方手部状态]。  
> 摄影机从[起始位置]以[运动方式]跟随[对象]，沿[路径]移动，最终停在[终点]。  
> 落幅时：[逐一说明人物落点、前后层次、身体朝向、目光、左右手和道具状态]。与下一镜衔接：[接点]。

*注：默认输出自然中文直出；若用户明确需要英文版，按精简执行版同步输出并保持角色特征、空间方位与左右手一致。*

**连续性核对：**
全程保持人物身份造型、地标空间关系、180° 轴线、既有手部道具归属及物理连续性；动作按顺序完整落稳。
